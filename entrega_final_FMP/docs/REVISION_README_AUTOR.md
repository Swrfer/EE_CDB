# Aclaraciones incorporadas a la entrega

El autor confirmó el nombre del curso, UNAM y el profesor Dr. Antonio Daniel
Martínez Gutiérrez; el origen de los 216 GED en tres cohortes GEO y TCGA-STAD,
contraste CG I–II vs TGC y filtrado por Hörtenhuber et al. (2017); el repositorio
Swrfer/EE_CDB y la necesidad de instalar dependencias y descargar datos desde cero.

La entrada externa local será un CSV clínico ACRG. El código genera los RDS TCGA
(conteos y clínica) y GEO. Los modelos y sus objetos se producen automáticamente.
Las pruebas científicas y sus parámetros confirmados se conservan.

No se añadieron requisitos adicionales del curso. El maestro registra el entorno
de cada nueva ejecución y las rutas LASSO/RSF/OOB al terminar all.

Las accesiones de los tres GEO del estudio diferencial previo, sus umbrales y
el entorno histórico completo no fueron aportados; no se inventan ni se pretende
reproducir aquí aquel estudio multicohorte. La lista fija de 216 genes se incluye.

La descarga real y la comprobación numérica de la nueva ejecución quedan pendientes
de correr el maestro con el CSV real. Los datos y versiones remotos pueden cambiar.
